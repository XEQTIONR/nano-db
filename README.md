<h3 align="center">Nano DB</h3>

<h4>About</h4>

<p>ERP app for Cross Country (previously Intertrac Nano)</p>

<a href="https://app.intertracnano.com">Live Site</a> (v3)

<h4>Features</h4>
<ol>
  <li>CRM - Basic information about customers.</li>
  <li>Orders and invoices - List of orders placed with details</li>
  <li>Payments and receipts - Payments received for orders sold</li>
  <li>Returns - Items that have bee returned by customers</li>
  <li>Inventory - Currently stock levels for all items</li>
  <li>Reports - Historical data for the above</li>
</ol>

<h4>Stack</h4>
<ul>
  <li>PHP (Laravel)</li>
  <li>React</li>
  <li>Inertia</li>
  <li>MySQL</li>
  <li>Tailwind</li>
  <li>shadcn/ui</li>
</ul>
